# SRM

Веб-приложение для управления и учета финансовых операций спортивного клуба.

## Стек

- React
- TypeScript
- Redux Toolkit
- RTK Query
- Node.js
- Express
- MongoDB
- Ant Design
- Recharts

## Функционал

- Учет доходов и расходов
- Управление финансовыми операциями
- Работа с сотрудниками
- Расчет заработной платы
- Статистика и аналитика
- Авторизация и разграничение доступа

## Запуск

Для работы приложения требуется локальная MongoDB.
запуск Node.js - npm start

### Frontend

```bash
npm install
npm run dev
```
